Windows快適な設定

作成したPythonプログラムを、コマンドプロンプトを開くことなくデスクトップからダブルクリック一発で安定起動し、専用アイコンやショートカットキーで快適に使うための設定メモです。

作成日2026年10月9日
作成ツールWindowsナレッジ
主な対象作成したPythonツールやスクリプトを手軽に日常使いしたい方

1. Pythonスクリプト起動用BATファイルの作成

Pythonプログラム（例：音読くん_ver04.py）を実行するたびにコマンドプロンプトを開いてコマンドを打ち込む手間を解消します。

よくある起動トラブル

  • パス迷子：ショートカット等から実行すると基準フォルダー（カレントディレクトリ）がズレて対象ファイルを見失う。
  • 日本語の文字化け：ファイル名やパスに日本語が含まれているとエラーで止まる。
  • 画面即落ち：エラー発生時に一瞬で黒い画面が閉じてしまい、原因が確認できない。

標準起動バッチファイルのテンプレート

Pythonスクリプトと同じフォルダー内に、以下の内容で run.bat（名前は自由）をUTF-8形式で作成・配置します。

@echo off
chcp 65001 > nul
cd /d "%~dp0"

python "音読くん_ver04.py"

pause

各行の役割と安定化のポイント

  • chcp 65001 > nul：文字コードをUTF-8に設定。日本語ファイル名の文字化け・実行失敗を防ぎます。
  • cd /d "%~dp0"：どこからショートカットで呼び出されても、バッチファイル自身の配置場所を作業基準フォルダーに固定します。
  • pause：実行終了後やエラー発生時に画面を自動で閉じず一時停止させ、メッセージを確認できるようにします。

2. お気に入りアイコン（.ico）の作成

デスクトップ上に配置したショートカットにアプリ専用のアイコンを適用すると、一目で分かりやすくなります。Windowsショートカットにはマルチサイズ対応の .ico 形式が必要です。

アイコン作成の2つの方法

  • 方法A（Web無料ツール）：「ICOコンバーター」サイト等を利用し、PNGやJPG画像をドラッグ＆ドロップで .ico に変換。
  • 方法B（Pythonスクリプト）：Pillow ライブラリを使って各解像度（16px〜256px）を含む高品質マルチサイズアイコンを一括生成： 
    from PIL import Image

img = Image.open("icon.png")
sizes = [(256, 256), (128, 128), (64, 64), (48, 48), (32, 32), (16, 16)]
img.save("app_icon.ico", format="ICO", sizes=sizes)

3. ショートカットの適用とホットキー割り当て

設定手順

  1. バッチファイルを右クリックして「送る」➔「デスクトップ（ショートカットを作成）」を選びます。
  2. デスクトップにできたショートカットを右クリックし、「プロパティ」を開きます。
  3. 「ショートカット」タブ ➔「アイコンの変更」➔「参照」から、作成した .ico ファイルを選択して適用します。
  4. ショートカットキー（ホットキー）の割り当て：
    同じプロパティ画面内の「ショートカット キー」欄をクリックし、お好みのキー（例：Ctrl + Alt + O）を押してOKをクリックします。
    以降はキーボードを押すだけで、いつでも一瞬でアプリが起動します。
