QRコード生成ツール

テキストやURLを入力するとその場でQRコードを生成し、PNG画像としてダウンロードできるツールです。処理はすべてブラウザ内で完結するため、入力した内容が外部サーバーに送信・保存されることはありません。

どんなときに使えますか

  • パソコンで見ているWebサイトのURLをスマホですぐ開きたいとき
  • 案内チラシや掲示物、名刺などに載せるQRコード画像を作りたいとき
  • 外部の生成サービスに送信したくない機密情報・社内テキストを安全にQRコード化したいとき

主な特徴

完全ブラウザ完結の安心設計

処理はすべてお使いのブラウザ内(JavaScript)で実行されます。入力したテキストやURLが外部サーバーへ送信・保存されることは一切ありません。ページを閉じれば入力内容も消去されます。

リアルタイム自動生成

テキストを入力すると自動でQRコードが即座にプレビュー表示されます。

ワンクリックでPNGダウンロード

生成されたQRコードは「PNGをダウンロード」ボタンを押すだけで画像ファイルとして保存できます。

サイズ・誤り訂正レベルのカスタマイズ

用途に合わせてサイズ（小180px〜特大400px）や、汚れに強い誤り訂正レベル（L〜H）を切り替えられます。

使い方

  1. 「ツールを開く」ボタンからアプリ画面を開きます。
  2. 「読み込むテキスト」欄に、QRコードにしたいURLやメッセージを入力します。
  3. 右側のプレビュー画面にQRコードが表示されます。必要に応じてサイズや誤り訂正レベルを変更します。
  4. 「PNGをダウンロード」ボタンを押すと、パソコンやスマホに画像が保存されます。

ご利用にあたって

  • 個人が作成したツールです。動作は保証しません。
  • 文字数が上限（目安：約2000文字）を超える場合や、内容によってはQRコードが生成できないことがあります。
  • 外部サーバーへの送信・保存は一切行われません。そのため、ページを再読み込みしたり閉じたりすると入力内容は消えます。
